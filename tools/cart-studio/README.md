# Slot Manager

Game transfers, library management, cartridge artwork and covers for Slot on Android. Runs on the device or in a browser connected to it. See [ANDROID.md](ANDROID.md) for building and integration.

Based on [Cart Studio](https://github.com/BrandonKowalski/slot-cart-studio) and [slot](https://github.com/BrandonKowalski/slot). Original attribution and licenses are retained.
