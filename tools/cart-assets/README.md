# Cartridge and Slot Asset Generation

Upstream source: [BrandonKowalski/slot](https://github.com/BrandonKowalski/slot) at commit `34ac38031fd903eb2a0a0157f1dea4d3a5546195` (v1.7.0). The original SVG silhouettes, painted cartridge textures (@MarkusMaribu), and Rust compositing routines are licensed under GPL-3.0-or-later; see the root `THIRD_PARTY.md` and `LICENSE`.

From the repository root, run with Rust 1.96 or newer:

```text
cargo run --locked --manifest-path tools/cart-assets/Cargo.toml
```

- `app/src/main/assets/cartridges/*.mask`: GBA, GB, and GBC silhouette masks used by the app (big-endian 32-bit width and height followed by an 8-bit coverage plane).
- `app/src/main/assets/cartridges/*.png`: runtime textures preprocessed with the 1 px transparent edge bleed from upstream `bitmaps.rs` (front shell, interior backing, and circuit board).
- `app/src/androidTest/assets/cartridges/*.argb`: reference images generated by the upstream Rust compositor for seven front shells, three clear interior backings, and three circuit boards (big-endian 32-bit width and height followed by row-major big-endian ARGB pixels).

GBA uses the upstream 360x212 logical canvas, and GB / GBC use 312x337; Android scales them to the active layout. Shell tinting preserves the upstream `Overlay` blend, 80% clear shell opacity (`CLEAR_ALPHA = 204`), and deterministic glitter highlights.

`silhouette.rs` rasterizes the SVG silhouettes into coverage masks; `material.rs` preserves the preprocessing and layered compositing functions from upstream `bitmaps.rs` and `cart.rs` to export label-free pixel references. Instrumented checks compare the Java renderer's integer pixels against these references across all three silhouettes, solid/clear/glitter finishes, and internal layers.

Normal Android builds consume the generated assets directly and do not require Rust.
